將線上網站的學習進度同步到本機 index.html。

## 執行步驟

1. 用 Chrome 擴充功能讀取線上進度：
   - 導航到 `https://sharonyen55.github.io/japanese-study/`
   - 執行 JS：`localStorage.getItem('jplearn_v2')`
   - 記下回傳的 JSON 物件

2. 若回傳為 null，告知使用者線上版尚無學習記錄，結束。

3. 將資料寫入本機 `D:\Sharon\AI\Life\Jepan\index.html`：
   - 找到這一行：`const SYNCED_PROGRESS = ...;`
   - 把整行換成：`const SYNCED_PROGRESS = <剛才取得的資料>;`

4. 告知使用者同步完成，並說明幾筆文法、幾筆單字已標記學會。
   - key 格式：`sid_gN` = 文法，`sid_vvN` = 單字

## 注意事項

- Chrome 擴充功能只需存取線上網址，不需要存取本機檔案
- 本機檔案由 Claude 的編輯工具負責更新
- 每次同步會完整覆寫上一次的紀錄
