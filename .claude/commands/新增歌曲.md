## 我負責處理

- 漢字標注假名 `漢字(ふりがな)`（正則只抓 `[㐀-鿿々〆ヶヵ]+` 漢字範圍，平假名不轉換）
- 每句歌詞中文翻譯
- 5 個文法句型（pattern、example、exampleZh、meaning、JLPT 等級）
- 5–6 個單字（word、reading、meaning、level、example、exampleZh）
- 整體難度評估與各等級佔比（N5+N4+N3+N2+N1 合計 100）

5. git add index.html && git commit -m "新增歌曲：歌名" && git push origin master:main

## 文法例句規則

- `example` 必須包含 pattern 核心字串（去開頭 `〜`、去 `（...）`、去中間 `〜` 或 `／`）
- 例：pattern `〜ずに` → 核心 `ずに`，example 中需含 `ずに`（注音夾中間也算）
- 從歌詞中選句，不要自創不在歌詞裡的例句

## 單字選詞規則

- 優先選 N3–N1 的詞（N5/N4 的超基礎詞跳過，除非對理解這首歌特別重要）
- example 必須是歌詞中實際出現的句子（同文法例句規則）
- 避免與同首歌的文法例句完全重複同一個 example 字串
- 資料格式：
  ```js
  {id:"v1", word:"覚悟", reading:"かくご", meaning:"覺悟、決心", level:"N2",
   example:"覚悟(かくご)で踏(ふ)み出(だ)し", exampleZh:"帶著覺悟踏出腳步"}
  ```
