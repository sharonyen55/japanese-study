# 🎵 歌詞で学ぶ 日本語

透過喜愛的歌曲學習日文文法的自學網頁工具。

🌐 **線上版本**：https://sharonyen55.github.io/japanese-study/

---

## 功能介紹

- **歌詞頁**：顯示日文歌詞與中文翻譯，漢字自動標注假名（振り仮名）
- **文法頁**：每首歌提取 5 個重點文法句型，附例句、例句中文翻譯與解說，文法用字以橘色標示，可標記已學會
- **學習進度**：首頁顯示整體文法完成率、各 JLPT 等級進度
- **歌手分類**：左側樹狀選單依歌手分類，可展開／收合，超出畫面可上下滑動
- **YouTube 連結**：每首歌附 MV 縮圖，點擊開啟 YouTube（建議搭配子母畫面同步聆聽）
- **回首頁**：點選左上角標題 🎵 歌詞で学ぶ 日本語 可回到首頁
- **手機支援**：響應式版面，手機可正常使用
- **離線可用**：所有資料內嵌於 HTML，不需伺服器

## 新增歌曲方法

### 步驟一：準備歌詞

將歌詞存入 `source/` 資料夾，格式為日文與中文交替，空行隔開：

```
# 歌曲名稱

暗(くら)い夜(よる)も
黑暗的夜晚也

迷(まよ)わず進(すす)もう
毫不猶豫地前行吧
```

注音寫法：`漢字(ふりがな)` → 網頁自動轉為 `<ruby>` 標籤，顯示於漢字上方

> ⚠️ **注意**：注音括號內只能是假名（平假名或片假名），含漢字或英文的不會被轉換。

### 步驟二：加入歌詞資料（index.html）

找到 `/* ── Raw lyrics ── */` 區塊，在最後一個 `LR[n]` 之後加入：

```javascript
LR[14] = `日文第一句
中文第一句

日文第二句
中文第二句`;
```

### 步驟三：加入歌曲資料（index.html）

在 `SONGS` 陣列最後一首後面加入：

```javascript
{
  id: 14,
  title: "歌曲名稱",
  artist: "演唱者",
  group: "所屬作品或團體",
  youtube: "影片ID",        // youtu.be/ 後面的部分
  note: "備註說明",
  level: "N4",              // 整體難度
  distribution: {N5:30, N4:35, N3:25, N2:8, N1:2},  // 各等級佔比（合計100）
  grammar: [
    {id:"g1", pattern:"〜ている", example:"例句(注音)", exampleZh:"例句中文翻譯", meaning:"中文說明", level:"N5", learned:false},
    {id:"g2", pattern:"〜たい",   example:"例句(注音)", exampleZh:"例句中文翻譯", meaning:"中文說明", level:"N4", learned:false},
    {id:"g3", pattern:"〜ずに",   example:"例句(注音)", exampleZh:"例句中文翻譯", meaning:"中文說明", level:"N3", learned:false},
    {id:"g4", pattern:"〜ように", example:"例句(注音)", exampleZh:"例句中文翻譯", meaning:"中文說明", level:"N3", learned:false},
    {id:"g5", pattern:"〜んだ",   example:"例句(注音)", exampleZh:"例句中文翻譯", meaning:"中文說明", level:"N4", learned:false}
  ]
}
```

> ⚠️ **文法例句規則**：`example` 必須實際包含 `pattern` 的核心字串（去掉開頭 `〜`、去掉 `（...）`、去掉中間 `〜` 或 `／` 後的部分），否則橘色高亮不會出現。
>
> 例：pattern `〜ずに` → 核心 `ずに` → `example` 中必須出現 `ずに`（允許中間夾注音，如 `届(とど)かずに`）

## 技術架構

| 項目 | 說明 |
|------|------|
| 語言 | 純 HTML + CSS + JavaScript，無任何框架 |
| 資料儲存 | 歌詞與文法資料全部內嵌於 HTML |
| 學習進度 | 儲存於瀏覽器 `localStorage`（各裝置獨立） |
| 假名標注 | `漢字(ふりがな)` 格式自動轉換為 `<ruby>` 標籤（僅限漢字範圍，平假名不轉換） |
| 文法高亮 | pattern 核心字串在例句中以橘色標示；先 highlight 再 ruby，避免標籤干擾搜尋 |
| 歌曲排序 | 數字 → 英文字母 → 日文五十音 |
| 部署平台 | GitHub Pages（免費） |

## 學習流程建議

1. **聽歌**：點 MV 縮圖開啟 YouTube，手機使用子母畫面（PiP）邊聽邊學
2. **看歌詞**：切換至「歌詞」頁，對照中文翻譯理解句意，注意假名注音
3. **學文法**：切換至「文法」頁，閱讀各句型說明、例句及中文翻譯，橘色為文法核心用字
4. **標記進度**：點擊文法卡片標記已學會，卡片變綠色
5. **追蹤進度**：點選左上標題回首頁，查看整體完成率
